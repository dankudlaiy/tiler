# Tiler

Автоматическая раскладка окон для Windows 10/11 в духе komorebi: все обычные окна на мониторе делят его
на плитки, а куда встанет окно, решает место, где ты его отпустил.

- **Перетаскивание.** Отпустил окно у края чужой плитки — встаёт с этой стороны, эта плитка делится пополам.
  В центре чужой плитки — окна меняются местами. Над своей плиткой — возвращается назад.
  Пока тащишь, поверх монитора видны «призраки» будущей раскладки; они плавно перетекают вслед за курсором.
- **Развёрнутые и полноэкранные окна** не трогаются: развернул — остальные сомкнулись.
  Потащил развёрнутое окно — оно восстанавливается и встаёт туда, куда его отпустили.
- **Новые, восстановленные и показанные окна** встают в раскладку сами; закрытые и свёрнутые уходят, соседи смыкаются.
- **Изменение размера.** Тянешь край плитки — общая граница с соседями сдвигается.
- **Окна меньше плитки** (галочка в трее). Окно, которое меньше своей плитки, стоит по её центру. Окна, которые приходят
  в раскладку, сохраняют свой размер (если окно больше плитки, оно сжимается до неё). Уменьшил окно — оно остаётся
  таким, соседи не двигаются, а место вокруг остаётся пустым. Потянул край дальше плитки — сдвигается граница с соседом,
  как обычно; растянул окно на всю плитку — оно снова её заполняет. Размер сохраняется, когда окно перетаскиваешь,
  сворачиваешь или переносишь на другой монитор.
- **Минимальные размеры.** Плитки не становятся меньше, чем окно готово сжаться (`WM_GETMINMAXINFO`).
  Если рядом не помещается, окно встаёт над или под соседом, а новое окно — в другую плитку, где есть место.
  Окно, которое не сжимается молча, Tiler замечает после первой попытки и переставляет.
- **Плавающее окно.** Отпусти окно с зажатым **Ctrl**, и оно выпадет из раскладки. Обычное перетаскивание вернёт его обратно.
- **Esc** во время перетаскивания отменяет.
- Всё сопровождается анимацией; окна едут к своим плиткам.

Не раскладываются: диалоги, окна поверх всех (картинка в картинке и т. п.), окна без изменения размера,
окна на других виртуальных рабочих столах.

Иконка в трее: пауза, «разложить заново», отступ, окна меньше плитки, скорость анимации, клавиша для плавающих окон, папка с логом.
Настройки и лог лежат в `%AppData%\Tiler`.

Встроенное прилипание Windows (Snap) при перетаскивании к краю экрана мешает; его можно выключить в
«Параметры → Система → Многозадачность → Прикрепление окон».

## Запуск

```bash
dotnet run --project src/Tiler
```

При старте Tiler просит права администратора, иначе Windows не даст двигать окна программ, запущенных от админа.

- `--no-elevate` — без прав администратора.
- `--only-title ПРЕФИКС` — песочница для разработки: раскладываются только окна, чей заголовок начинается с префикса;
  может работать рядом с обычным экземпляром.

```bash
dotnet test
```

## Устройство

- `src/Tiler.Core` — логика без Win32: `Workspace` — дерево разбиений одного монитора (добавить окно в точку,
  переместить, убрать, изменить размер), зоны сброса `DropZones`.
- `src/Tiler` — трей-приложение WPF:
  - `TilerController` — хуки `SetWinEventHook` (перетаскивание, показ/скрытие, сворачивание, смена положения),
    по `Workspace` на монитор;
  - `OverlayWindow` — прозрачный оверлей с призраками раскладки;
  - `Animator` — плавное перемещение окон, по потоку на окно и по одному `SetWindowPos` на кадр;
  - `WindowOps` — какие окна раскладывать, поправка на невидимую рамку (`DWMWA_EXTENDED_FRAME_BOUNDS`).
